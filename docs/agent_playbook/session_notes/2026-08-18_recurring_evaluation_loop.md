# Recurring Evaluation Loop Added

Date: 2026-08-18

Agent: Codex

Task: Update the agent playbook to capture replay-first ML testing and an
ongoing weekly/data-threshold evaluation loop for new real data.

## Summary

Updated the project handoff docs to make the desired operating loop explicit:

- test ML, prompt, parser, scoring, and risk changes on replay first
- collect real live decisions over time
- refresh outcome labels automatically
- run weekly or data-threshold-based reports on new real data
- refresh ML datasets/reports after enough new data or material fixes
- run replay regression after important changes before trusting live behavior

## Design Decisions

- Weekly is documented as the default human-review cadence.
- A data threshold is recommended so tiny weekly samples do not create fake
  confidence.
- Replay regression is documented as mandatory for material fixes and prompt
  changes.
- ML refreshes are tied to meaningful new labels or meaningful system changes
  rather than blind retraining.

## Risks Or Caveats

- The weekly report script is not implemented yet.
- The replay regression script is not implemented yet.
- Thresholds such as 50 decisions/outcome labels are starting defaults and may
  need adjustment after observing actual live data volume.
